When: ANY call that costs money (Groq vision or chat, Speechify, paid images, an API key) and any time Marko asks "how much did we spend", "what does this cost", "cost agent".
Rule (Marko, 13.11.2026: "We almost spent all my savings on Groq recognizing images ... anything which costs money, it needs to ask me and give me how much money it costs"): you ask the Cost Agent BEFORE a paid call. Your own code already does it for vision, book, brain and news (qwen_app/cost_gate.py); a NO or no answer means the call does not happen and you do not retry or go around it.
For a new batch job that calls /api/vision/ask: pass `job` (a name) and `job_items` (how many pictures). Marko is asked once: "Are you sure? This will cost about $X (N image recognitions with Groq)". A job that passes its estimate by 20 % asks again. A job with no size is granted $0.25 at a time.
Ask by hand: `costagent ask "<who>" "<what>" <provider> <estimate_usd> --items N --job J` (exit 0 = YES, 1 = NO). Tell what was really spent: `costagent spent "<who>" <provider> <usd> --job J`.
The numbers (today / week / month per provider and process): `costagent status`, or the app Cost Agent (Mantra) in the star menu. The VM asks the Mac's gate over Tailscale (~/.config/cost-agent/url and token): if the Mac is off the VM cannot spend, by design.
Never name or print a key. Zero-cost paths (free keys, local Whisper, Edge TTS, grab mode with no vision) need no question.
